# THE HAMJA EXPERIENCE

A responsive, static multi-page portfolio for Jobayer Hamja, built with HTML, CSS, and vanilla JavaScript. The art direction is Midnight Editorial: midnight navy, charcoal blue, warm ivory, muted champagne, desaturated teal, and slate.

## Pages

- `index.html` — Home dashboard and navigation hub
- `about.html` — Six-chapter personal editorial and supplied portrait
- `education.html` — KUET, HSC, and SSC timeline
- `skills.html` — Technical foundations coursework, programming and computation, electronics, engineering disciplines, digital and web, creative, and music categories
- `projects.html` — Two completed personal projects with real screenshots and official live links, plus the academic Bus Ticket Reservation System
- `bus-ticket-reservation.html` — Academic C programming project overview for the Bus Ticket Reservation System
- `creative.html` — Music journal, seven Instagram posts, university stage experience, creative arts, and Beyond the Degree interests
- `writing.html` — Cinematic reading experience for “Life Is a Film, Not a Race”
- `cv.html` — Personal dossier, actual CV download, and printable profile link
- `cv-print.html` — Print-friendly profile
- `contact.html` — Email and verified social profiles

All main pages share the same navigation, logo, footer, color system, and responsive behavior. Reduced-motion preferences are respected. The contact page uses direct email and profile links; there is no pretend message form.

## Creative Corner

The music journal includes the seven supplied Instagram links using the official embed script, with direct links for fallback. The videos are not downloaded, modified, or rehosted. The stage section describes university concert experience without fabricated event details or placeholder media. The personal interests area contains all eight supplied categories in a two-column editorial layout.

## Run locally

Open `index.html` in a browser or serve this folder with any static file server. Local asset and page links use relative paths for GitHub Pages compatibility.

## Update supplied assets

- Replace `assets/images/profile.jpg` for the home and dossier portrait.
- Replace `assets/images/about-portrait.jpg` for the About page portrait.
- Replace `assets/images/projects/bonny-birthday-edition.jpg` or `assets/images/projects/dr-nesaruddin-portfolio.jpg` to update project screenshots. The current files are screenshots, not placeholder artwork.
- Replace `assets/jobayer-hamja-cv.pdf` to update the downloadable CV. The PDF is an optional download and is not embedded as the main CV experience.
- Add or remove Instagram performance URLs in the `posts` array in `script.js`.

## GitHub Pages deployment

1. Create a repository for the site and upload the contents of this folder to the repository root.
2. In repository **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and `/(root)`.
3. Save the setting and open the GitHub Pages URL shown in repository settings.
4. Check page navigation, Instagram embeds and fallback links, project destinations, social links, and the CV download after deployment.

Deployment has not been performed from this workspace.
